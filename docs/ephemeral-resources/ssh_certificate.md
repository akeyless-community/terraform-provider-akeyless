# akeyless_ssh_certificate (Ephemeral Resource)

Generates an SSH certificate without storing it in Terraform state. Terraform opens ephemeral resources on plan and apply, so each plan issues a certificate that apply does not use. Terraform does not revoke plan-time certificates.
